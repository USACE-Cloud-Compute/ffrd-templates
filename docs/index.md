# FFRD Directory Structure

The standard FFRD basin project directory structure is displayed in the interactive graphic
below, with descriptions of the intended content in each sub-directory. An empty
template directory, which includes the descriptions in README files, is available as a
download.

stored under OneDrive or a long network path.</p>
