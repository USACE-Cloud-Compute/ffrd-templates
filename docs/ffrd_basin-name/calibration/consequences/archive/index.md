# archive

This folder contains *archived* structure inventories that represent earlier versions of the inventory in the calibration phase.

The nsi year should reflect the year (version) of the nsi, and the year of the price level should reflect the price level year if prices are indexed, the yyyymmdd represents the date of the archive of the inventory.

Naming convention: &lt;modeling-unit&gt;-nsiyyyy-pricelevelyyyy-yyyymmmdd.gpkg
