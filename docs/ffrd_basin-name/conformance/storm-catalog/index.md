# storm-catalog

This folder contains the storm catalog for the basin.

The **catalog.grid** files contain pointers to all storms in the catalog. It also includes the **transposition domain** and **watershed boundary**.

The **storms** subdirectory contains all precipitation and temperature data in .dss file format.

The **fishnets** folder contains valid placement points for each transposed storm.

The **seasonality-distributions** folder contains the storm-typed seasonalities and govern when storms of a given type can occur within the calendar year.
